# Denmark Eats Direct

I need a website for a restaurant which consists of the restaurants menu from which if the customer  orders the items from this website it much reach the server of the owner, it must notify the owners about the order . The restaurant name is "DENMARK RESTAURANT" which must printed in the front page of the website. The main theme is to provide authentic non vegetarian foods,  in chinese and arabian format in a state like Tamil nadu.  So add some 3d videos and pictures according to this theme and give me nearly 100 buttons to add the dishes and its price.  In simple words I need a website which  contains the menu and can be ordered by the customers.  At the end of the ordering process it must contain 2options "DINE IN and DELIVERY" which notifies  that the cutomer is interested in dining or take away the order.  The menu must only be edited by the main server.  Strictly every informations should only be modified by the main server ie the owner. The customers should only have the visibilities of restaurant details, items to order, total, and the dining options.  It must contain an owner option from which only the owner can access every actions. To change the owner mail id there must be a two step authentication . This shop has nearly 3 branches. So I under the owner option it must be seperated as branch 1, 2 and 3 which must be accessable only by the 3main servers
